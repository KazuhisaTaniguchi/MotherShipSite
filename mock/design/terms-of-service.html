この利用規約（以下「本規約」）は、【未確定：運営者の名前】（以下「運営者」）が提供するリモートデスクトップアプリ「Mothership」の使い方について、運営者と利用者のみなさまとの間の約束を定めるものです。

かんたんにまとめると

  • つないでよいのは、自分のMacか、持ち主から許可をもらったMacだけです。
  • はじめてMacにつないだ日から14日間、すべての機能を無料で試せます。そのあとは、一度の購入でずっと使えます。月額料金はありません。
  • 代金の支払いと返金は、App Store・Google Playの決まりにしたがいます。
  • 画面と操作は、Macとデバイスの間で直接やり取りします。Mothershipのサーバーは通りません。
  • Tailscale・Aqua Voice・BlackHoleは、ほかの会社などのサービスです。それぞれの規約にしたがってお使いください。

このまとめは、読みやすくするためのものです。正式な内容は、以下の各条のとおりです。

第1条この規約について

  1. 本規約は、本アプリ（第2条で定めます）を使うすべての方に適用されます。
  2. 利用者は、本アプリを入れて使いはじめた時点で、本規約に同意したものとみなします。同意いただけない場合は、本アプリを使わないでください。
  3. 未成年の方は、保護者など法定代理人の同意を得たうえでお使いください。
  4. App Store・Google Playなど、本アプリを配布するストアの規約と本規約の内容が異なる場合、そのストアから入手した本アプリについては、ストアの規約が優先する範囲で、ストアの規約が適用されます。

第2条用語の意味

本規約で使う言葉の意味は、次のとおりです。

本アプリ
操作されるMacに入れる「Mothership Host」と、操作する側のiPhone・iPad・Android・Macに入れる「Mothership」をまとめた呼び方です。更新版や、関連する説明・ウェブサイトを含みます。
ホストのMac
Mothership Hostを入れ、離れた場所から操作されるMacです。
デバイス
Mothershipを入れ、ホストのMacを操作するiPhone・iPad・Android・Macです。
ストア
App Store、Google Playなど、本アプリの配布や代金の支払いを行うサービスです。
ライセンス
本アプリを、試用期間のあともずっと使える権利です。第6条の購入で手に入ります。

第3条使ってよい範囲

  1. 運営者は利用者に対し、本規約にしたがって本アプリを使う権利を与えます。この権利は、利用者だけのもので、ほかの人に譲ったり、貸したりすることはできません。
  2. 本アプリは、利用者自身がMacを使うためのものです。個人の用途のほか、仕事で自分の作業に使うこともできます。
  3. 本アプリそのものの権利は、利用者に売り渡すものではありません。利用者が手に入れるのは、本規約の範囲で使う権利です。

第4条必要な環境と準備

  1. 本アプリを使うには、運営者がウェブサイトなどで案内する環境（たとえば、Mothership Hostは macOS 14以降）が必要です。案内した環境でも、機種や設定によっては、一部の機能が動かないことがあります。
  2. Mothership Hostが画面を映し、キーボードやマウスの操作を伝えるには、ホストのMacで「画面収録」と「アクセシビリティ」を許可する必要があります。許可は、利用者の判断で行ってください。
  3. 操作できるのはMacだけです。WindowsやLinuxのパソコンは操作できません。
  4. 外出先から使うには、ホストのMacとデバイスに、Tailscaleのアプリを入れておく必要があります。声で入力する機能を使うには、ホストのMacに「Aqua Voice」と「BlackHole 2ch」を入れておく必要があります。これらは、本アプリには含まれません（第12条）。
  5. ホストのMacがスリープしているとき、電源が入っていないとき、ログインしていないときは、接続できません。通信にかかる料金は、利用者の負担です。

第5条試用期間

  1. 本アプリは、ホストのMacごとに、はじめてデバイスからの接続が成り立った時点から14日間、すべての機能を無料で試せます（以下「試用期間」）。
  2. 試用期間が終わると、ライセンスを購入するまで、デバイスからそのMacに接続できなくなります。接続中に試用期間が終わったときは、その時点で接続が切れます。
  3. 試用期間の残りは、Mothership Hostのメニューバーとメニュー、およびデバイスの画面でお知らせします。
  4. アプリの入れ直し、時刻の変更、保存されたデータの削除などで、試用期間をやり直したり延ばしたりしないでください（第10条）。

第6条購入（買い切り）

  1. ライセンスは、買い切りです。一度購入すれば、月額料金や更新の料金はかかりません。価格は、ストアの購入画面に表示される金額です。
  2. ライセンスは、デバイスのMothershipの中から、ストアの決済で購入します。購入できるデバイスとストアは、運営者がウェブサイトなどで案内します。
  3. 購入したデバイスからホストのMacに接続すると、そのMacが購入済みになります。一度の購入で、利用者が持っているMacを何台でも購入済みにできます。購入済みになったMacには、どのデバイスからでも接続できます。
  4. デバイスの機種を変えたときや、アプリを入れ直したときは、「購入を復元」で、同じストアのアカウントの購入を引き継げます。
  5. ライセンスは、購入した利用者のためのものです。ほかの人が持つMacを購入済みにするために使わないでください。

第7条支払いと返金

  1. 代金の支払いは、ストアが行います。支払いの方法、税金、領収書などは、ストアの規約と表示にしたがいます。運営者は、利用者のクレジットカードなどの支払いの情報を受け取りません。
  2. 返金は、ストアの決まりと手続きにしたがって、ストアに申し出てください。運営者は、ストアを通さずに直接返金することはできません。
  3. 返金を受けた場合、そのライセンスは失われます。返金を受けたライセンスで購入済みにしたMacを、引き続き使わないでください。
  4. 試用期間があるため、購入の前に、お使いの環境で動くことを確かめてから購入してください。

第8条つないでよいMac

  1. 本アプリでつないでよいのは、利用者自身が持っているMac、または持ち主や管理者から操作の許可をもらっているMacだけです。
  2. 勤め先や学校のMacにつなぐときは、その組織の決まりにしたがってください。許可が必要なときは、先に許可をもらってください。
  3. ホストのMacをほかの人も使っている場合、その人に知らせずに、画面を見たり操作したりしないでください。

第9条利用者が管理すること

  1. ホストのMacとデバイスは、利用者の責任で管理してください。とくに、デバイスには、パスコードやFace ID・Touch ID・指紋によるロックをかけておくことをおすすめします。
  2. デバイスをなくしたとき、手放すときは、Mothership Hostのメニューの「登録済みの端末」から、そのデバイスを削除してください。削除したデバイスからは、接続できなくなります。
  3. Tailscaleのアカウントなど、外部のサービスのアカウントとパスワードは、利用者の責任で管理してください。
  4. 本アプリの「画面を隠す」機能は、ホストのMacのそばにいる人から画面を見えにくくするためのものです。すべての状況で画面が見えないことを保証するものではありません。Macの近くに人がいる場所では、十分に注意してお使いください。
  5. 大切なデータは、利用者自身でバックアップを取ってください。

第11条データの扱い

  1. 画面の映像、キーボードやマウスの操作、クリップボード、ファイル、音、声は、ホストのMacとデバイスの間で、暗号化して直接やり取りします。Mothershipのサーバーは通りません。運営者は、これらの中身を受け取りません。

  4. 個人の情報の扱いについては、別に定めるプライバシーポリシーにしたがいます。
