MOTHERSHIPの使いはじめかた

Macに入れてつなぐまでと、声で書くための準備を、順番に説明します。
上から順に進めれば、ひととおり使えるようになります。

このページでは、離れた場所から操作されるMacを「Mac」、手もとのiPhone・iPad・Androidを「デバイス」と呼びます。アプリは2つあります。Macに入れる「MOTHERSHIP HOST」と、デバイスに入れる「MOTHERSHIP」です（アプリの画面では、「Mothership Host」「Mothership」と表示されます）。図は、説明のためのイメージです。実際の画面とは、見た目がちがいます。

はじめてつなぐMacに入れて、QRコードで登録して、つなぐまで 声で書く準備をするAqua Voice と BlackHole 2ch の入れ方と設定 外から使うTailscaleの準備と、出かける前の確認 うまくいかないときつながらない、映らない、声が入らない

かんたんにまとめると

  • MacにMOTHERSHIP HOSTを入れて、2つの許可をオンにします。
  • デバイスにMOTHERSHIPを入れて、MacのQRコードを読み取ります。
  • 「接続」をタップすると、Macの画面が手もとに映ります。ここまでで、家の中で使えます。
  • 声で書くには、MacにAqua VoiceとBlackHole 2chを入れて、Aqua Voiceのマイクを「BlackHole 2ch」にします。
  • 外から使うには、MacとデバイスにTailscaleを入れます。

2つの許可は、何に使う？「画面収録」は、Macの画面をデバイスに映すために使います。「アクセシビリティ」は、デバイスからのキーボードやマウスの操作を、Macに伝えるために使います。

3-1Aqua Voiceを入れる

Aqua Voiceの公式サイト（aquavoice.com）から、Mac版をダウンロードして入れます。Apple シリコンのMacにも、IntelのMacにも対応しています。

入れたら、まずMacの前でふつうに使えることを確かめます。メモなど、文字を打てる場所をクリックします。キーボードの fn キーを押している間だけ話して、離します。話した文が入れば、大丈夫です。

メモ

明日の会議は、10時からです。

話す「明日の会議は、10時からです」

聞き取り中

fn⌃⌥⌘⌘⌥
録音のキーは、fnのままに。MOTHERSHIPは、Aqua Voiceの「fnを押している間だけ聞き取る」動きを使います。Aqua Voiceの録音のキーを別のキーに変えていると、デバイスから話しても文字になりません。Aqua Voiceのはじめの設定は fn です。変えたかどうかは、Aqua Voiceの設定の「Keybindings」で確かめられます。

3-2ターミナルを開く

ここからは、Macにはじめから入っているアプリ「ターミナル」を使います。ターミナルは、文字の命令（コマンド）でMacを動かすアプリです。むずかしく見えますが、このページのコマンドを、そのまま貼り付けるだけです。

  1. ⌘（command）キーを押しながら、スペースキーを押します。検索の欄（Spotlight）が出ます。

  2. 「ターミナル」と打って、return キーを押します。

  3. 文字だけのウィンドウが開きます。ここにコマンドを貼り付けて return キーを押すと、実行されます。

return

コマンドのコピーのしかたこのページの紺色の枠の中をクリックすると、コマンド全体が選ばれます。⌘＋C でコピーし、ターミナルで ⌘＋V で貼り付けて、return キーを押します。

3-3Homebrewを入れる

Homebrew（ホームブルー）は、Macにソフトを入れるための、無料の道具です。BlackHole 2chを入れるのに使います。

  1. もう入っているか、確かめます。次のコマンドを実行します。

    brew --version
    • 「Homebrew」と数字が出たら、もう入っています。3-4 BlackHole 2chを入れるへ進みます。
    • 「command not found」と出たら、まだ入っていません。次へ進みます。

  2. Homebrewを入れます。次のコマンドを実行します（1行です）。

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    • 「Password:」と出たら、Macにログインするときのパスワードを打って、return キーを押します。打った文字は画面に出ませんが、入力されています。
    • 「Press RETURN/ENTER to continue」と出たら、return キーを押します。
    • 数分かかります。途中で「Command Line Tools」という部品も、いっしょに入ります。
    • 「Installation successful!」と出たら、終わりです。

  3. 「Next steps」のコマンドを実行します。最後のほうに「Next steps:」と出て、その下に、コマンドが2〜3行書いてあることがあります。出ていたら、その行をコピーして、1行ずつ実行します。ターミナルからHomebrewを使えるようにするための設定です。

    たとえば、次のようなコマンドです（これは例です。実際は、あなたの画面に出たものを使ってください）。

    echo >> ~/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

  4. 入ったことを確かめます。もう一度、次のコマンドを実行します。「Homebrew」と数字が出れば、成功です。

    brew --version

Macの前でも、今までどおり使えます

「Aqua VoiceのマイクをBlackHole 2chにしたら、Macの前で話しても聞こえないのでは？」と思うかもしれません。大丈夫です。

MOTHERSHIP HOSTが動いている間は、Macの前でも、今までどおりAqua Voiceを使えます。あなたがMacの前でAqua Voiceを使うと、MOTHERSHIP HOSTが、Macのマイクの音をBlackHole 2chに渡すからです。fn キーを押して話せば、今までどおり文字になります。マイクを切り替える必要は、ありません。

  • Macのスピーカーやマイクの設定は、変わりません。BlackHole 2chを入れても、音の通り道が1つ増えるだけです。
  • Macの前で使うマイクは、「システム設定」›「サウンド」›「入力」で選んでいるマイクです。イヤホンのマイクなどに替えても、そのまま使えます。
  • Macのマイクを使うのは、Aqua Voiceが聞き取っている間だけです。
  • デバイスから話している間は、デバイスの声だけをAqua Voiceに渡します。

気をつけること（3つ）
  • マイクの許可：はじめてのとき、MOTHERSHIP HOSTが「マイク」の許可を求めます。「許可」を選んでください。
  • MOTHERSHIP HOSTを終了しているとき：Macの前で話した声が、Aqua Voiceに届きません。MOTHERSHIP HOSTの「ログイン時に起動」をオンにしておくと安心です（5 Macを起こしておく）。MOTHERSHIP HOSTを使わない日は、Aqua Voiceのマイクを元のマイクに戻せば、元どおり使えます。
  • 「サウンド」の入力：「システム設定」の入力を「BlackHole 2ch」にしていると、Macの前の声は渡されません。入力は、いつものマイクにしておきます。

4外から使う（Tailscale）

家の外からつなぐには、「Tailscale（テイルスケール）」を使います。Tailscaleは、離れた機器どうしを安全につなぐサービスで、個人なら無料で使えます。ルーターの設定を変える必要は、ありません。

  1. Tailscaleのアカウントを作ります。

  2. MacとデバイスにTailscaleのアプリを入れて、同じアカウントでログインします。

  3. 家のWi-Fiで、いちどMOTHERSHIPでMacにつなぎます。デバイスが、外からのつなぎ先を覚えます。

  4. 出かける前に、試します。スマホのWi-Fiを切ってモバイル回線にし、MOTHERSHIPの「接続」をタップします。Macの画面が映れば、準備は終わりです。

MOTHERSHIPのサーバーは通りません。ルーターの設定も、要りません。

外では、デバイスのTailscaleがオンになっていることを確かめて、「接続」をタップするだけです。Macのところに「○ 自宅 LAN では見つかっていません（外出先は Tailscale で接続）」と出ていても、そのまま「接続」を押せます。

つながらないときデバイスの「アドレスを直接入力」に、MacのTailscaleの名前（例：my-mac.tail1234.ts.net）を入れて試します。名前は、Tailscaleのアプリで確かめられます。
外からつないだときの、Macの画面

外からつなぐと、自宅のMacの画面は、自動で隠れます（家にいる人に見えないようにするため）。切断すると、Macはロックされます。

デバイスの設定「外出先から接続したら、自宅の Mac の画面を自動で隠す」と、MOTHERSHIP HOSTの「画面を隠していたときは、切断したら Mac をロックする」で、変えられます。
