# HERO の動画の置き場所

**（2026-11-21：HERO を Fold7 のアニメに作り直したので、動画に替わる仕組みは無くなった。実機の動画に替えるときは、モックは `index.html` の `.hx` の中、本番は `frontend/src/components/HeroFold.tsx` を差し替える）** 以下は前の HERO の決まり（記録）。

ここに **`hero-demo.mp4`** を置くと、LP の HERO（端末の枠の中）で、自作のアニメーションの代わりにその動画が自動で再生されます。HTML・CSS・JS を変える必要はありません。
ファイルが無い間は、自作のアニメーション（イメージ。`../README.md` を参照）が動きます。

## 動画の決まり

| 項目 | 内容 |
|---|---|
| ファイル名 | `hero-demo.mp4` |
| 形式 | MP4（H.264）。音声なし（音は再生されません） |
| 形 | 縦長。iPad の画面そのまま（1640×2360 と同じ比率、約 7:10）。端末の枠・余白は付けない（枠は CSS で描いています） |
| 大きさ | 横 820〜900px ほどで十分（表示は最大 430px 幅） |
| 長さ | 15〜20 秒。最後と最初がつながって見えるように（繰り返し再生されます） |
| 重さ | 3MB 以内を目安 |

比率が違う動画を置くと、枠に合わせて上下か左右が切り取られます（`object-fit: cover`）。横向きの場面を入れるときは、枠の作りを変える必要があります。

## 撮る内容（台本の案）

1. （0〜3 秒）Mothership の最初の画面で、登録済みの Mac をタップ
2. （3〜7 秒）Mac のデスクトップが画面いっぱいに映る。指でスクロール、ウィンドウをタップ
3. （7〜12 秒）アプリ内キーボードを出して、ショートカットバーから操作（アプリの切り替えなど）
4. （12〜18 秒）🎤 ボタンを押して話す → 文字が入る（「声で入力」を見せる場合）。または文字入力の欄で日本語を打つ

写り込みに注意：Mac のデスクトップ（開いている窓、Dock、メニューバー、通知）に、個人の情報や関係のないアプリが映らないようにします。

## 撮り方

- **実機の画面収録（おすすめ）**：iPhone のコントロールセンターの「画面収録」。実際の指の操作と滑らかさが映ります。撮ったあと、上の決まりに合わせて切り出します。
- **シミュレーター**：`xcrun simctl io <ID> recordVideo --codec h264 <ファイル>`。シミュレーターは外からタップを送れないので、アプリの QA 用の起動引数（`-selfTest ui-connected`）で画面を順に切り替えます。指の動きは映りません。
  - ペアリング用のリンクの渡し方：MacBook Air の Mothership で Mac mini につないだまま、Mac mini の Mothership Host →「端末を追加…」→「リンクをコピー」。クリップボードの共有で MacBook Air に届きます。リンクはノートやログに書き残しません。
  - つなぐ前に `QA連携/ステータス.md` の「ホストの接続ロック」に記入（接続は 1 つだけ。撮影中はほかのデバイスの接続が切れます）。
- 切り出し・変換：macOS 標準の `avconvert`（`--start`・`--duration`・`--preset Preset960x540` など）。
