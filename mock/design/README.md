## 見方

アプリの画面の画像を `../contents/images/` から読むので、**テーマのフォルダ（`MotherShip_template/`）から配信**して開きます。

```
cd MotherShip_template
python3 -m http.server 8765 --bind 127.0.0.1
# ブラウザーで http://127.0.0.1:8765/design/
# デザインシステムの見本帳は http://127.0.0.1:8765/design/designSystem/
```

（`index.html` を直接開く方法は確かめていません。）

## この案の特徴

- **HERO は動きが主役。** iPad の枠の中で、使い方の流れを見せる自作のアニメーション（約 22 秒で 1 周）が動きます。HTML・CSS・JS で描いたもので、動画ファイルではありません。
  - 5 つの場面：つなぐ → Mac の画面が、手元に → キーボードで操作 → 声で入力 → 向きを変えても、ぴったり（iPad を横向きにすると Mac の画面も横長に変わり、縦に戻すと縦長に戻る）。
  - **本物の操作の録画ではありません。** Mac の画面・書類・キーボードは説明用に描いたもので、枠の下に「イメージです（実際の画面とは異なります）」と表示しています。最初の場面の上の部分だけ、実画面の静止画を使っています。
  - 枠の下に再生／一時停止のボタンと、いまの場面の名前。画面の外に出たら止まります。
  - 「視差効果を減らす」を設定している人には動かさず、Mac の画面が映った場面で止めておきます（ボタンで再生できます）。
  - **本物の動画に差し替えるとき**：`media/hero-demo.mp4` を置けば、アニメの代わりにその動画が再生されます（コードは変えなくてよい）。
  - 場面の時刻や文は `script.js` の `SCENES`・`TEXT`・`render` にまとまっています。確認用に、ブラウザーのコンソールで `__heroDemo.seek(8300)` のように時刻（ミリ秒）を指定して止められます。
- **「声で入力」の節。** Aqua Voice との連携（🎤 を押して話すと、Mac に文字が入る）を紹介します。Aqua Voice が別の会社のアプリであること、BlackHole 2ch の準備が要ることを、囲みで書いています。
